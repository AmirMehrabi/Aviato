# Aviato Marketing Homepage Design System

## Product context

A Persian-first RTL cloud infrastructure brand for founders, developers, and business teams who need virtual machines with clear resources, predictable pricing, NVMe storage, dedicated IPs, and Persian support. The homepage should feel authored, calm, trustworthy, and operationally credible rather than like a generic AI SaaS template.

## Visual direction

Editorial minimalism with a crisp near-white canvas, deep navy type, Aviato blue accents, restrained cards, and real brand assets. Use the existing Aviato logo and hero imagery. Keep the hero message readable, with generous negative space and one clear primary CTA. Avoid decorative gradients, excessive glassmorphism, neon effects, and dashboard clutter.

## Tokens

- Font: IranSans, Dana, Estedad, Pelak, Vazirmatn, ui-sans-serif
- Ink: #0f172a / slate-950
- Muted: #475569 / slate-600
- Blue: #0069FF
- Blue dark: #0050D0
- Blue pale: #EEF5FF
- Page: #F5F8FD
- White: #FFFFFF
- Borders: #E2E8F0
- Radius: 12px controls, 24px cards, 28px feature panels
- Shadow: subtle slate-tinted elevation, never heavy by default
- Direction: RTL
- Layout: max-width 80rem, 1rem mobile gutters, 2rem tablet, 2.5rem desktop

## Interaction

Use short transitions, hover elevation only on interactive cards, sticky shrinking header, and a mobile drawer menu. Preserve accessible focus states, readable contrast, and no horizontal overflow.
